# 🌟 Kerala State School Kalolsavam 2026 (Thrissur)

An interactive, modern, lightning-fast Progressive Web App (PWA) companion for the **64th Kerala State School Kalolsavam 2026** in Thrissur (January 14 – 18, 2026).

---

## ✨ Key Features & Enhancements

- 🏛️ **25 Stage Directory**: Visual stage cards with real venue images, venue locations, and quick actions.
- 🗺️ **Google Maps Navigation**: One-tap smart navigation to any venue across Thrissur.
- ⚡ **Universal Instant Search**: Real-time program search across 400+ events with keyword highlighting.
- 🏷️ **Category & Grade Filters**: Filter instantly by Dance, Music, Instruments, Drama, Fine Arts/Literary, Recitation, High School (HS), and Higher Secondary (HSS).
- 📅 **Interactive Day-by-Day Schedule**: Seamless schedule explorer across Day 1 to Day 5.
- ⭐ **Personal Itinerary & Bookmarks**: Save favorite events with offline persistence (`localStorage`).
- 📆 **Export to Calendar (.ics)**: Download personal schedules into Apple Calendar, Google Calendar, or Outlook with exact event dates and venue details.
- 📱 **Progressive Web App (PWA) & Offline Ready**: Service Worker caching allows attendees to view stages and timetables even in crowded festival grounds with spotty cellular coverage.
- 📍 **Thrissur Venues Directory**: Geographical clusters (Thekkinkadu Maidan, Town Hall, St. Thomas College, CMS, Holy Family, etc.) for quick route planning.
- 🚨 **Emergency & Helpline Directory**: Quick dial for Police (112), Medical/Ambulance (108), Fire (101), KSRTC, and Railway helpline.
- 🎨 **Modern Festival UI**: Glassmorphism, golden festival accents, responsive desktop tab navigation, and mobile bottom navigation bar.

## 🚀 How to Deploy to Vercel

This repository is pre-configured with `vercel.json` and optimized for instant zero-config deployment to [Vercel](https://vercel.com/).

### Option 1: Deploy with Vercel CLI
1. Open PowerShell / Terminal in this project directory:
   ```bash
   cd c:\Kalotsav_2026
   ```
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the quick prompts to link and deploy your site.

### Option 2: Deploy via GitHub (Recommended for automatic CI/CD)
1. Initialize a git repository and push your project to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete modern rework for Kalotsav 2026"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/Kerala_School_Kalotsav_2026.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Click **Deploy**. Vercel will automatically host the static application with clean URLs and security headers.
